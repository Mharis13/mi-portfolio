# Portfolio personal — Mario Ban

Portfolio académico de Desarrollo de Aplicaciones Web con proyectos, habilidades y formación.

**Web:** https://mharis13.github.io/mi-portfolio/

## Tecnologías
HTML5, CSS3, JavaScript y GitHub Pages.

## Estructura
- `index.html`: contenido y navegación.
- `css/`: estilos y diseño responsive.
- `js/`: menú móvil y tema.
- `img/`: favicon.

Para probarlo, abre index.html en un navegador. Para publicar, configura GitHub Pages desde la rama main y la carpeta raíz.
